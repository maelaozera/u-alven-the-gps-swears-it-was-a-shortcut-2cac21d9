## The entry

The program writes the GPS's own one-line excuse for sending the driver down the wrong road — delivered in classic GPS voice ("In 200 feet, turn left..."), smug and defensive, with a fresh, specific detail and a punchline the reader does not see coming: the "shortcut" leads straight into a wedding, and the GPS takes full credit for the bride's grand entrance.

## How to run

Requires Node 22 or later. From the repository root:

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` (1–200 characters, one line of plain text) and self-checks the character limit before writing.
